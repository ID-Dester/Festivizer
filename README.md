# Garland for Windows

Festivizer для Windows 11 x64: гирлянда у нижней панели задач и рамка одного активного обычного окна. Сборка 0.2.3 подготовлена для испытаний, но версия ещё не принята: обязательная матрица GUI и длительные измерения не завершены. [Проверка на других ПК](docs/TestingOnOtherPCs_0.2.3.md); [текущий статус](docs/ReleaseValidation_0.2.3.md).

Для обнаруженной проблемы «рамка за окном» подготовлена сборка-кандидат по [ТЗ 0.2.1](doc/GarlandForWindows_0.2.1_FrameFix_SPEC.md). Выполненные проверки и остающиеся блокеры описаны в [отчёте 0.2.1](docs/Review_0.2.1.md).

[ТЗ 0.2.2](doc/GarlandForWindows_0.2.2_MenuAndLifecycle_SPEC.md) описывает доработку меню и жизненного цикла рамки; фактически выполненные проверки и ограничения приведены в [отчёте 0.2.2](docs/Review_0.2.2.md).

По результатам контрольного прогона подготовлено [ТЗ стабилизации проверки и приёмки 0.2.2](doc/GarlandForWindows_0.2.2_ValidationFix_SPEC.md): ожидание foreground, явные результаты тестов, карта покрытия и повторные прогоны. Это задание на доработку, а не подтверждение готовности версии.

По итогам независимой проверки стенда подготовлено [ТЗ исправления замечаний и финализации ветки 0.2](doc/GarlandForWindows_0.2_Finalization_SPEC.md): два дефекта popup-стенда, сквозное покрытие, borderless fullscreen, полная регрессия, замеры и выпуск кандидата 0.2.3. Это план оставшихся работ; текущая версия по-прежнему не принята.

## Запуск и управление

Для проверки сначала завершите предыдущий экземпляр из трея, затем запустите `GarlandForWindows.exe` из полной папки соответствующей сборки. Главное окно не открывается; пункты управления находятся в системном трее, возможно в скрытых значках. В меню доступны общий выключатель, отдельные переключатели панели и рамки, настройки и выход. Второй экземпляр в том же сеансе не запускается.

В настройках доступны четыре темы, яркость 10–100%, скорость 25–200% и добровольный автозапуск. Изменения применяются кнопкой «Применить»; «По умолчанию» меняет только черновик до применения. Автозапуск записывается только при явном применении пользователем и требует сохранения всей папки публикации на месте.

Настройки хранятся в `%AppData%\GarlandForWindows\settings.json`, диагностика — в `%LocalAppData%\GarlandForWindows\diagnostics.log`. При более новой версии схемы сохранение блокируется до явного сброса через настройки.

## Сборка и проверки

Требуются Windows 11 x64 и .NET 10 SDK:

```powershell
dotnet build GarlandForWindows.sln -c Release
dotnet run --project tests/GarlandForWindows.Tests -c Release
dotnet run --project tests/GarlandForWindows.DesktopTests -c Release
dotnet publish src/GarlandForWindows/GarlandForWindows.csproj -c Release -r win-x64 --self-contained true -o artifacts/publish/win-x64-0.2.3-candidate
```

Тестовые проекты — автономные наборы проверок без внешнего тестового фреймворка; оконному тесту нужен интерактивный рабочий стол Windows. Публикация может потребовать загрузки компонентов; `artifacts/` исключён из Git. Для переноса self-contained версии копируйте всю папку, а не один exe.

Оконный стенд сохраняет новые прогоны в `artifacts/validation/0.2.3/<run-id>/`, не меняя историю 0.2.2. Код выхода: 0 — PASS, 1 — FAIL, 2 — SKIP, 3 — BLOCKED. При ограничении Windows на автоматическую активацию можно отдельно запустить стенд с `--interactive` и выбрать его тестовое окно. Логический набор с сохранением результатов: `./tests/Run-LogicValidation.ps1 -Configuration Release`. Карта покрытия и незакрытые сценарии: [TestCoverage 0.2.2](docs/TestCoverage_0.2.2.md).

В разработке 0.2.3 добавлен supervisor: `./tests/Run-DesktopSupervisor.ps1 -Configuration Release` (для ручного выбора окна добавить `-Interactive`). Он сохраняет результаты в `artifacts/validation/0.2.3/<run-id>/`; прямой запуск DLL остаётся диагностическим. Supervisor и покрытие пока не прошли все обязательные проверки ТЗ, поэтому команда не означает готовности к приёмке.

Поддерживаемая конфигурация — один монитор и стандартная нижняя Taskbar. Подробный статус и непроверенные сценарии: [отчёт 0.2](docs/Review_0.2.md) и [ограничения](docs/KnownLimitations.md). Архитектура: [Architecture](docs/Architecture.md); требования: [ТЗ 0.2](doc/GarlandForWindows_0.2_SPEC.md) и [исходное ТЗ](doc/GarlandForWindows_SPEC.md).
