# Garland for Windows

Лёгкое приложение для Windows 11, которое украшает панель задач и рамку активного обычного окна новогодней гирляндой.

Проект находится на этапе подготовки базовой структуры. Текущая спецификация MVP 0.1: [doc/GarlandForWindows_SPEC.md](doc/GarlandForWindows_SPEC.md).

## Требования

- Windows 11 x64
- .NET 10 SDK
- WPF и Win32 API (P/Invoke)

## Структура

- `src/GarlandForWindows/` — приложение WPF.
- `tests/GarlandForWindows.Tests/` — тесты независимой логики.
- `doc/` — спецификация и технические требования.
- `docs/` — заметки по реализации и ограничения.

## Начало работы

Исходный проект приложения пока не создан. Реализация должна следовать этапам и ограничениям MVP в спецификации. После добавления solution сборка выполняется командой:

```powershell
dotnet build -c Release
```

Результат сборки сам по себе не подтверждает корректную работу оконных overlay и требует отдельной ручной проверки на Windows 11.

## Область MVP 0.1

- Гирлянда на верхнем крае нижней панели задач.
- Гирлянда вокруг одного активного обычного окна.
- Анимация, управление из системного трея и click-through overlay.
- Обработка перемещения, изменения размеров, DPI, fullscreen и перезапуска Explorer.

Меню «Пуск», Windows 10, ARM и нестандартные оболочки не входят в обязательную область MVP.
