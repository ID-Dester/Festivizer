# Garland for Windows

Прототип MVP для Windows 11 x64: гирлянда у нижней панели задач и рамка одного активного обычного окна. Код и сборка подготовлены; обязательные сценарии GUI ещё не пройдены полностью, поэтому MVP не принят.

## Запуск

Запустите `artifacts/publish/win-x64/GarlandForWindows.exe` после публикации. Приложение не открывает главное окно; управление и выход находятся в меню значка в системном трее (значок может находиться в скрытых значках). Второй экземпляр не запускается. Для опубликованной автономной сборки SDK не нужен.

## Сборка и проверки

Требуются Windows 11 x64 и .NET 10 SDK:

```powershell
dotnet build GarlandForWindows.sln -c Release
dotnet run --project tests/GarlandForWindows.Tests -c Release
dotnet publish src/GarlandForWindows/GarlandForWindows.csproj -c Release -r win-x64 --self-contained true -o artifacts/publish/win-x64
```

Тестовый проект — автономный исполняемый набор проверок геометрии, без внешнего тестового фреймворка. Публикация может потребовать загрузки пакетов среды выполнения. `artifacts/` исключён из Git.

## Ограничения и проверка

Поддерживаемая конфигурация MVP — один монитор и штатная нижняя панель задач Windows 11. Развёрнутые окна не украшаются. Fullscreen определяется по совпадению границ монитора и отсутствию обычной рамки; возможны пропуски нестандартных приложений. Рамка помещается в обычную группу Z-order, а гирлянда панели — в topmost-группу; корректность при переключении окон и играх требует проверки. Подробнее: [KnownLimitations](docs/KnownLimitations.md), [спецификация](doc/GarlandForWindows_SPEC.md).
