# Карта покрытия 0.2 — промежуточное состояние

Версия для испытаний, не итог приёмки. Идентификаторы и отдельные уровни M01–M10, F01–F10 и H01–H08 сохранены в [карте 0.2.2](TestCoverage_0.2.2.md); её исторические результаты не переносятся автоматически на 0.2.3. Ниже — дополнения и открытые условия [ТЗ финализации](../doc/GarlandForWindows_0.2_Finalization_SPEC.md). Идентификация сборки и серии приведены в [отчёте](ReleaseValidation_0.2.3.md).

| Требование | Уровень и свидетельство | Состояние / оставшийся пробел |
|---|---|---|
| V01 | Детерминированные тесты `MenuObservation`; положительный реальный popup в серии DesktopTests | ЧАСТИЧНО: негативные сценарии не выполняют всю реальную оркестрацию popup и cleanup. |
| V02 | Supervisor: искусственные PASS, авария, зависание без окна; 5 Debug + 5 Release, последняя серия `desktop-20261110-153941-*`–`153950-*` | ЧАСТИЧНО: не доказаны все ветви отказов через адаптеры, бюджеты и уборка в полном наборе сценариев. |
| C01 / M01–M10, F01–F10 | Исторические уровни в карте 0.2.2; DesktopTests на собственных HWND | ЧАСТИЧНО: не доказаны все последовательности через production host, доставка hook, факты Windows и тайминг реального Dispatcher. |
| F01 fullscreen | Логические границы/стили, узкий тест CS2; пользовательская короткая проверка CS2 на сборке `0.2.3-candidate-20261110-cs2` | ЧАСТИЧНО: журнал новой сборки недоступен, версия/режим игры и срабатывание правила не подтверждены им; браузерное видео, автоскрытие панели и остальные условия не проверены. |
| H01–H08 | Историческая карта, инструкция для ручного сеанса | NOT_RUN для полной матрицы на идентифицированной итоговой сборке. Короткая проверка CS2 — отдельное свидетельство. |
| R01.1–R01.8 | Часть логических проверок в `GarlandForWindows.Tests` | ЧАСТИЧНО: ручная и системная регрессия не выполнена полностью. |
| P01 | Предварительных результатов, удовлетворяющих протоколу, нет | NOT_RUN: четыре режима, сравнение с 0.1 и 30 минут. Запланировано на других ПК. |
| A01 | Self-contained сборка и локальный манифест для проверки | ЧАСТИЧНО: чистая Windows без .NET и полная приёмка не подтверждены, публикация на GitHub ожидает короткой проверки. |

Статусы не скрывают невыполненные условия. Для каждого последующего испытания записывайте run-id, сборку и хеши, компонент, уровень доказательства, фактический результат и остающийся пробел.
