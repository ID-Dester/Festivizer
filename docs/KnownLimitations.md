# Состояние и известные ограничения

Сборка 0.2.3 для проверки CS2 подготовлена, но **не принята**. Пользователь сообщил об успешной короткой проверке CS2; требуется проверка идентифицированной финальной сборки и остальные сценарии. Актуальный статус — [ReleaseValidation 0.2.3](ReleaseValidation_0.2.3.md). Длительные испытания и проверка на других ПК запланированы после размещения версии на GitHub; это ещё не результаты.

Для наблюдавшегося сочетания процесса CS2, стиля и геометрии добавлено узкое правило fullscreen. Другие стили и игры этим исключением не покрываются. Диагностический журнал новой сборки при последней проверке не удалось обнаружить; поведение диагностики требуется проверить отдельно.

Исторический статус 0.2.2:

Кандидат 0.2.2 подготовлен, но не принят: требуемая ручная матрица ещё не выполнена на опубликованном бинарнике. Результаты и хеши приведены в [отчёте 0.2.2](Review_0.2.2.md).

Стенд DesktopTests доработан после ранее зафиксированного отказа предусловия foreground. Две ограниченные серии сохранены; последняя серия 5 Debug и 5 Release завершилась с кодом 0. Это подтверждает оконные тесты с собственными HWND, а не ручную матрицу. [Отчёт стабилизации](ValidationReport_0.2.2.md) и [карта покрытия](TestCoverage_0.2.2.md) перечисляют оставшиеся пробелы.

- Системное menu-mode читается у Windows для текущего GUI-потока; непарные события не являются постоянным флагом скрытия. Нестандартные меню, не отражённые `GetGUIThreadInfo`, могут не обнаруживаться.
- Owner/Z-order и контроллер проверены автоматически и на собственных тестовых HWND; переходы через настройки, треевое и контекстные меню Проводника/браузера, DPI и 100 переключений для кандидата требуют ручной проверки.
- При контрольном прогоне отчёта 10.11.2026 прошли 127 автопроверок, но DesktopTests после 9 PASS остановился на предусловии `controller test foreground is target`; popup и контроллер в этом повторе не проверены. Первоначальный успешный результат не отменён, однако его воспроизводимость пока не подтверждена. Подробности — в контрольном разделе отчёта.
- Для некоторых окон ранее наблюдался отказ доступа при создании рамки; предусмотрено безопасное скрытие и задержка повторов. Совместимость с окнами другого уровня прав не подтверждена.
- В 0.2.2 ранее наблюдалась декорация поверх borderless-игры; эвристика fullscreen в той версии не менялась. Результаты 0.2.3 описаны выше.
- Длительные измерения 0.2 и запуск публикации на чистой Windows без .NET не выполнены. NU1900 означает, что данные аудита NuGet получить не удалось.

История: [Review 0.2.1](Review_0.2.1.md) и [Review 0.2](Review_0.2.md). Требования: [ТЗ 0.2.2](../doc/GarlandForWindows_0.2.2_MenuAndLifecycle_SPEC.md).
