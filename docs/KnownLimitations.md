# Известные ограничения

На текущем начальном этапе приложение и его overlay ещё не реализованы. Поддерживаемая среда и ограничения MVP описаны в [спецификации](../doc/GarlandForWindows_SPEC.md).

Реальную совместимость, производительность и поведение Z-order необходимо проверять на Windows 11; успешная компиляция не заменяет GUI-проверку.
