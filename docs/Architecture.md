# Архитектура прототипа 0.2.2

Приложение использует WPF для окон и рисования, Windows Forms — только для значка и меню трея, Win32 P/Invoke — для геометрии, событий и стилей. `App` управляет mutex и жизненным циклом; `ApplicationHost` связывает компоненты, а `WindowTracker` и `TaskbarTracker` получают сведения об окне и панели.

`SettingsService` хранит версионированный JSON в `%AppData%`, `SettingsWindow` редактирует черновик, `AutoStartService` работает только с собственным значением HKCU Run. `VisibilityPolicy` и `GeometryPolicy` содержат независимые вычисления. `GarlandOverlay` проверяет необходимые стили до показа и скрывается при ошибке позиционирования; графический компонент кэширует провод, лампы и кисти по размеру и теме, а фаза анимации зависит от времени и выбранной скорости.

`RefreshScheduler` объединяет входные события до постановки в Dispatcher. Резервная сверка работает раз в 500 мс; во время move/resize включается дополнительная сверка раз в 34 мс, прекращаемая после окончания операции или смены цели. Анимация с интервалом 34 мс останавливается, когда обе гирлянды скрыты. Координаты Win32 физические, размеры рисунка в DIP; отступы преобразуются по DPI целевого окна.

`WinEventRouter` разделяет системные и объектные события; `MenuStateTracker` считывает menu-mode текущего GUI-потока через `GetGUIThreadInfo` и возвращает Unknown при ошибке или смене контекста. События только запрашивают сверку. Тестируемый `FrameOverlayController` работает через адаптеры Windows/WPF; при невозможности освободить старый живой overlay новый не создаётся.

`FrameOverlayController` создаёт рамку как owned-окно актуального HWND и проверяет owner, стили и относительный порядок; при смене цели старый экземпляр закрывается. При обычном изменении координат Z-order не меняется. При отказе для одной цели следующая попытка откладывается на пять секунд. Topmost-окна исключены из рамки. Гирлянда Taskbar помещается в topmost-группу и должна скрываться при полноэкранном конфликте. Поведение рамки для всех целевых процессов и меню требует дополнительной ручной проверки.
